# 数据知识产权协商估值引擎

> 基于《德阳市数据知识产权登记管理办法（试行）》的 L1+L2+L3 三层估值工具

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 📋 简介

本工具为数据知识产权协商估值提供可视化计算引擎，完全基于德阳市制度原文实现，适用于：
- 市监局数据知识产权登记估值
- 交易双方协商定价参考
- 论文实证研究工具

## 🧮 三层估值结构

### L1：成本法公式
```
A = a + (d+e)·b + a·c
```
- `a`：数据直接成本（数据购买 + 劳务 + 设备折旧）
- `d+e`：加工成本（数据加工 + 设备运维）
- `b`：加工成本系数（0.2~1.2）
- `c`：附加值系数（0.1~0.8）

### L2：系数自动推荐
根据**运算流程数**和**判定条件数**自动判定难度等级，结合场景等级给出推荐系数。

### L3：交叉验证
与中评协收益法评估值对比，偏差 >15% 时自动告警。
