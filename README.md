# 数据知识产权协商估值引擎

> 基于《德阳市数据知识产权登记管理办法（试行）》的 L1+L2+L3 三层估值工具

![Version](https://img.shields.io/badge/version-1.3.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 📋 简介

本工具为数据知识产权协商估值提供可视化计算引擎，完全基于德阳市制度原文实现，适用于：
- 市监局数据知识产权登记估值
- 交易双方协商定价参考
- 论文实证研究工具

## 🧮 三层估值结构

### L1：成本法公式
```
A = a + (d+e)·b + a·c
```
- `a`：数据直接成本（数据购买 + 劳务 + 设备折旧）
- `d+e`：加工成本（数据加工 + 设备运维）
- `b`：加工成本系数（0.2~1.2）
- `c`：附加值系数（0.1~0.8）

### L2：系数自动推荐
根据**运算流程数**和**判定条件数**自动判定难度等级，结合场景等级给出推荐系数。

### L3：交叉验证
与中评协收益法评估值对比，偏差 >15% 时自动告警。

## ✨ v1.1 新功能：导出与二维码闭环

v1.1 新增「导出与复核」模块，实现估值报告的生成→传递→回填→校验全闭环：

- **📄 导出 CSV**：一键导出当前案例全参数 + 计算结果为 CSV 文件（带 UTF-8 BOM，Excel 直接打开不乱码）
- **🖼️ 导出带二维码报告**：生成含全部参数、公式溯源、二维码的完整估值报告（模态框预览）
- **📷 扫码回填复核**：浏览器调用摄像头（getUserMedia）扫描报告二维码，自动回填参数并重算校验
- **🖼️ 上传报告图片解码**：上传含二维码的报告图片，前端 jsQR 解码后回填校验
- **🖨️ 打印报告**：打印友好的报告模板，含公式溯源与系数依据

### 二维码闭环价值

市监局、数据交易所现场出报告 → 对方扫本工具生成的码即知参数与估值，杜绝「手工填错/被篡改」。纯前端、不依赖 API 额度。

### 安全加固

- CSV 注入防护（`=+-@` 开头自动转义）
- 二维码数据类型与边界校验
- QR 数据精简（只存核心入参，可重算的 result 不入码）

## ✨ v1.2 新功能：外部报告提取

v1.2 新增「外部报告提取」模块，支持扫描/上传第三方《数据资产评估报告》二维码，或粘贴报告正文，自动提取成本构成与加工方法，映射填入估值模型：

- **📷 上传报告二维码图片**：前端 jsQR 解码外部报告二维码（支持 JSON / URL / 文本三种格式）
- **📷 摄像头扫外部报告**：getUserMedia 实时扫码
- **📝 粘贴报告文本提取**：双路径提取
  - **🔍 规则解析（离线）**：正则匹配成本构成、流程数、场景等级，零网络依赖
  - **🤖 AI 语义提取（需 API）**：调用 LLM 处理非标报告格式，自动输出结构化 JSON
- **自动回填 + 校验**：提取结果映射到模型字段，与报告原估值比对，偏差分级告警

### AI 提取配置

AI 路径需在「⚙️ AI 提取配置」中填写 API endpoint、key 和模型名。支持任何 OpenAI 兼容 API（如 glm-5.2）。⚠️ AI 提取 prompt 经外部服务器，医疗/患者敏感数据勿走此路径。

### 双路径价值

规则解析路径保证离线可用（无网/无额度时仍可工作）；AI 路径处理非标报告格式，是 v1.3/v1.4 智能化评估的基础能力。

## ✨ v1.3 新功能：加工难度系数 b 五子系数精细拆分

v1.3 将粗粒度的 b 推荐升级为**可编程、多维、可解释**的五子系数模型，依据 **GB/T 36344 数据质量框架**与**中评协《资产评估专家指引第9号》**：

| 子系数 | 维度 | 分档依据 |
|---|---|---|
| **B1** | 流程拓扑复杂度 | 原子处理步骤数（≤2/3-4/5-6/≥7） |
| **B2** | 业务规则复杂度 | 原子判定规则数（≤3/4-6/7-12/≥13） |
| **B3** | 质量治理负荷 | 质量维度数 + 检查规则数，取较高档 |
| **B4** | 多源异构整合 | 源系统数 + 格式类别数，取较高档 |
| **B5** | 安全合规与受控交付 | 受控措施数，隐私计算/可信空间直接 4.0 |

- 统一四档尺度 `{1.0, 1.7, 2.7, 4.0}`
- 双权重方案：**W1 成本敏感专家权重**（推荐）/ W0 等权基准
- 合成公式：`b = 0.30×B1 + 0.25×B2 + 0.20×B3 + 0.15×B4 + 0.10×B5`（W1）
- **校准演示**：省人民医院×扬子江案例可精确复现 b=1.4（B1/B2=1.7，其余 1.0 → 1.385 → 1.4）
- 精细模式为**可选增强**，默认关闭，不影响现有简易模式交互
- 纯前端离线，AI 抽取路径规划于 v1.3.1
