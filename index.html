这是什么

本工具基于《德阳市数据知识产权协商估值指南（试行）》（德市监函〔2025〕42号）的成本法协商估值方法，帮助权利方与相对方对数据知识产权快速测算、协商一个双方认可的估值。所有金额单位均为 万元。

核心公式（L1）

A = a + (d + e) × b + a × c
  • a 审定直接投入成本 = 数据购买 + 必要劳务 + 必要设备
  • d 必要设备成本，e 必要劳务成本，d+e 即加工必要成本
  • b 加工难度系数（L2 推荐），c 应用场景价值系数（L2 推荐）

三层结构怎么用

  • L0 成本输入：填 a 的三项构成（数据购买 / 劳务 / 设备），系统自动汇总为 a
  • L2 系数推荐：填运算流程数、判定条件数 → 自动判定难度等级并给 b 的范围；选应用场景等级 → 给 c 的范围。系数可在范围内由双方协商微调
  • L3 交叉验证：填第三方收益法评估值，系统自动算偏差%。≤5% 绿色可信，5–15% 黄色建议复核，>15% 红色需重新商定

数据从哪来

  • 成本数据由权利方提供、双方共同审定
  • 收益法评估值来自中评协备案的资产评估机构报告，仅用于结果校验
  • 点「加载真实案例」可一键填入省人民医院×扬子江（98.8万）全套参数作参照

注意

  • 系数 b、c 在系统推荐范围内由双方协商确定，不是系统自动给出唯一值
  • 本工具为协商辅助，最终估值以双方签署的确认书为准

分步计算
a = 26.0 (直接投入成本)
d + e = 20.0 + 6.0 = 26.0 (加工成本)
b = 1.4 (加工难度系数)
c = 1.4 (应用场景价值系数)
(d+e) × b = 26.0 × 1.4 = 36.4
a × c = 26.0 × 1.4 = 36.4
A = a + (d+e)×b + a×c = 26.0 + 36.4 + 36.4 = 98.8 万元
